Pylint Typecheck Messages to Pyrefly

Pylint is a linter, but its typecheck checker reports many of the same problems as a type checker, such as missing attributes and bad call arguments. If you use Pyrefly, you can usually disable these Pylint messages and rely on the corresponding Pyrefly error kinds instead.

There is no automatic migration from Pylint. Use the table below to find the Pyrefly error kind to configure or suppress in place of each Pylint message. For example, # pylint: disable=no-member corresponds to # pyrefly: ignore[missing-attribute].

How to read the table​

The Enabled by column shows which presets report each Pyrefly error kind:

  • basic: every preset except off. This includes the basic preset, which Pyrefly uses when it finds no configuration.
  • default: every preset except off and basic.
  • strict: only the strict and all presets. These error kinds are off by default.

You can also turn individual error kinds on or off with the errors setting.

Complete mapping​

The mapping was checked by running Pyrefly on the example code from each message's page in the Pylint documentation.
